# Kalyan TR — Portfolio

Single-page portfolio for audit visibility and inbound.

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

## GitHub Pages (recommended)

1. Create a repo named `tr-Kalyan.github.io` (user site) **or** enable Pages on any repo from `/docs` or `gh-pages`.
2. Copy these files to the repo root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `favicon.svg`
3. Settings → Pages → Deploy from `main` / root.
4. Update the `canonical` and Open Graph URLs in `index.html` to the live domain.

## What this page is optimized for

- Protocol founders scanning for an auditor in under 20 seconds
- Contest organizers checking validated Highs
- Recruiters looking for associate / junior SR with a regulated QA background
- Share cards on X via Open Graph + Twitter meta
